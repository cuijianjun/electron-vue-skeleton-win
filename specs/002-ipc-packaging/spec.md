# 002 — IPC 与打包优化

目标：采用共享会话的集中通信、异步配置缓存、订阅作用域和分阶段打包思路，适配现有 Electron44 / Vue3 / Vite 项目。

通信只有共享协议文件能触及原生请求/事件；保留发送者、路由、文件授权和更新安全边界。页面使用业务 API，配置异步初始化，旧同步接口只读内存。跨窗口配置通知有版本，卸载只清自己的订阅，早到的子窗口/深链消息可消费。

打包拆分编译/目录/安装包；复用必须校验源码、工具链、模式和输出指纹。启用 ASAR，保留运行依赖/许可和平台安装钩子；保留中英文语言资源。相同机器架构测量前后时间与体积，不借用参考项目数字。

验收：单元/真实 Electron/热更新/HMR/ASAR 打包启动；Windows 真实安装与升级；UOS 真机条件继续独立标记。保存现有基线和迁移提交，新增提交并推送现有 GitHub 功能分支，不合并 main。
